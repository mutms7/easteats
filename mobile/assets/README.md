The icons are rasterized from the existing East Eats vector logo at `public/icon-maskable.svg`, using `mobile/scripts/build-icons.mjs` from the repository root. The iOS icon is an opaque 1024 x 1024 PNG. Android's adaptive foreground preserves transparency, and the app config supplies the flame background.

Plus Jakarta Sans is downloaded from the official Google Fonts repository (`ofl/plusjakartasans/PlusJakartaSans[wght].ttf`). Its SIL Open Font License is included beside the font. No AI image generation was used.
